# 🤝 Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto!

## 🚀 Flujo de Trabajo

1. **Haz un Fork** del repositorio.
2. **Crea una Rama de Característica** (`git checkout -b feature/NuevaFuncionalidad`).
3. **Realiza tus Cambios** manteniendo los estándares de código limpio (Clean Code).
4. **Haz Commit de tus Cambios** (`git commit -m 'feat: Añadir nueva funcionalidad'`).
5. **Haz Push a la Rama** (`git push origin feature/NuevaFuncionalidad`).
6. **Abre un Pull Request**.

## 📐 Estándares de Código

- Utiliza convenciones de nombres claras y explicativas.
- Mantén las funciones pequeñas y enfocadas en una sola responsabilidad (SRP).
- Incluye comentarios descriptivos únicamente donde aporten valor técnico.
